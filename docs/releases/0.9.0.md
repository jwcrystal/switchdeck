# SwitchDeck 0.9.0

Text recognition arrives, three switches join the menu, and the app can tell you
when a newer release is out.

## New

- **Recognize Text.** A new menu switch reuses the screenshot overlay: pick a region or window and its text and QR codes are read on this Mac with Vision. A result window shows the image next to editable text to copy; Silent recognition copies straight away and shows a toast instead. It has its own pane in Settings with a shortcut, Auto copy, what to do with a QR link (copy or open it), and how long the toast stays up.
- **Result window.** Its layout follows the capture and it opens at a size that fits the image and the number of lines. The text is selected on open, so ⌘C copies it and typing replaces it; ⌘↩ and Esc work at once. Join Lines merges wrapped lines into one paragraph, and Open Link appears for http(s) QR codes.
- **Dock Autohide** switch.
- **Mute Sound** and **Mute Microphone** switches. They mute the current output or input device without touching its volume; a device with no settable mute shows "Not available".
- **Keep Display On** in the Keep Awake submenu stops the screen from turning off as well as the Mac from sleeping. It is remembered across launches.
- **Check for Updates…** in the menu compares the running version with the latest GitHub release and offers the download page. SwitchDeck never checks on its own.
- **Screenshot selection** uses a white frame and dims everything outside the region; hovering a window with no selection cuts it out of the dimming.

## Fixed

- The selection outline could end up in the recognised image; the region is now captured while the overlay is still up, with its windows excluded.
- Recognition models load at launch and when a selection starts, so the first recognition no longer waits for them.
- The frozen screenshot is snapped to device pixels, so it no longer looks soft next to the live screen.
- The Empty Trash count is read in the background, so a busy Finder no longer stalls the menu.
- The permission setup window: Screen Recording rows mention Recognize Text and offer Relaunch once the grant is requested, the signing note reflects the actual signature, the redundant "Not Now" button is gone, and the last untranslated strings are localised.

## Known limits

- Scrolling capture is still paused.

## Download

`SwitchDeck-0.9.0.zip` is signed ad-hoc, so macOS blocks the first launch:

1. Move `SwitchDeck.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/SwitchDeck.app` does the same from a terminal. Because the signature is not a Developer ID, an update can ask for Accessibility, Automation and Screen Recording again. Recognize Text needs Screen Recording.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
