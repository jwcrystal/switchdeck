# SwitchDeck 0.7.3

Patch release. Nothing in the switches or the editor changed; the interface is
translated all the way through now.

## Fixed

- **The last three menu items were still English** in an otherwise Chinese menu: `Permissions…`, `Settings…` and `Quit SwitchDeck` were never routed through the translation lookup, and the same applied to the alert's `OK` and `Open Privacy Settings` buttons.
- The localisation check now fails when user-facing AppKit text (menu titles, alert buttons, label and button titles) is a bare literal, which is the failure that let those rows ship.
- The README's clone line uses the real repository URL instead of a placeholder.

## Download

`SwitchDeck-0.7.3.zip` is signed ad-hoc, so macOS blocks the first launch:

1. Move `SwitchDeck.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/SwitchDeck.app` does the same from a terminal.

The zip's SHA-256 is attached next to it. Because the signature is not a Developer ID, an update can ask for Accessibility, Automation and Screen Recording again.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
