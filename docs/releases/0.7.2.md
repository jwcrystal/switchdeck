# SwitchDeck 0.7.2

First public release. The source is here, and the release attaches an ad-hoc signed zip built by CI. There is no notarised download yet.

## What it is

A menu-bar app with sixteen one-click system switches and a screenshot editor that opens in place, over the region you selected. Native Swift, no third-party dependencies, no sandbox, no App Store.

- **Switches** — hidden files, desktop icons, screen clean, keep awake, dark mode, keyboard lock, screen lock, Night Shift, Stage Manager and its autohide, empty trash (with item count), empty pasteboard, recording, screenshot, quit all apps, eject disks.
- **Shortcuts** — a global shortcut per switch, recorded in Settings, with Carbon conflict reporting.
- **Screenshot editor** — region, window and full-screen capture; rectangle, ellipse, line, arrow (straight, curved, elbow), freehand, highlighter, text, numbered markers, mosaic, blur; copy, save, pin; undo and redo.
- **Two languages** — English and Traditional Chinese, switchable in Settings › General › Language.

## Download

`SwitchDeck-0.7.2.zip` is signed ad-hoc, so macOS blocks the first launch:

1. Move `SwitchDeck.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/SwitchDeck.app` does the same from a terminal. Right-click → Open no longer works on macOS 15 and later.

The zip's SHA-256 is attached next to it: `shasum -a 256 SwitchDeck-0.7.2.zip` should match.

Because the signature is not a Developer ID, an update can ask for Accessibility, Automation and Screen Recording again. Building from source and running `scripts/setup-signing.sh` once avoids that on your own machine.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)

## Install

```bash
git clone https://github.com/jwcrystal/switchdeck.git
cd switchdeck
swift test
./scripts/setup-signing.sh   # once per machine, keeps permission grants across rebuilds
./scripts/build-app.sh
open build/SwitchDeck.app
```

The first time a switch needs a permission, SwitchDeck shows its setup window; that window is the only place macOS prompts.

## Known limitations

- **Scrolling capture is paused.** The engine is in the source but unreachable from the app: the stitching still duplicates content on some pages. Region, window and full-screen capture are unaffected.
- **Not on the App Store, by design.** Lock Screen and Night Shift use private APIs, and the app is not sandboxed, so App Review would reject it. Private APIs can also break after a macOS update; a failing switch explains itself instead of crashing.
- **No notarised download.** Build from source, or notarise your own Developer ID build.
- **Two languages only.** A language without a `.lproj` file falls back to English.
