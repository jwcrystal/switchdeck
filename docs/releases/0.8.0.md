# SwitchDeck 0.8.0

Window capture, done properly. Until now clicking a window only used its bounds
as a region on the full-screen frame, so anything in front of that window ended
up in the screenshot and there was no shadow.

## New

- **A window is captured as a window.** `SCContentFilter(desktopIndependentWindow:)` grabs that window alone, so overlapping windows no longer appear, and the shadow is drawn by us instead of letting ScreenCaptureKit shrink the window to fit its own.
- **⇧-click picks several windows.** They are composed on one canvas by their position on screen; `Return` edits the result, `Esc` clears the selection, and the pending windows are outlined while you pick.
- **The canvas fits the selection.** The old fixed 28pt margin around the frame is gone: a single window uses its real bounds, several windows use their union, and only pixels that leave the screen are cropped — nothing is scaled or re-centred.
- **The app's own Settings window can be captured.** The picker used to skip every window owned by SwitchDeck and only accept normal-level windows, so the Settings window and its floating panels were unreachable. Only the capture overlay is excluded now, by window ID.

## Testing

`swift test` covers the composer maths and the selection path. The two tests that
grab real pixels need Screen Recording and run with `SWITCHDECK_LIVE_CAPTURE_TESTS=1`;
CI skips them.

## Known limits

- Composing across two screens is not supported; one composition stays on one screen.
- JPEG flattens the transparent corners to white; PNG and HEIC keep them.
- Scrolling capture is still paused.

## Download

`SwitchDeck-0.8.0.zip` is signed ad-hoc, so macOS blocks the first launch:

1. Move `SwitchDeck.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/SwitchDeck.app` does the same from a terminal. Because the signature is not a Developer ID, an update can ask for Accessibility, Automation and Screen Recording again.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
